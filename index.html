Local-first privacy

z3d's CS Enhancer is designed around local processing. Player analysis and application data are intended to remain on the user's own PC. Match demos can be processed temporarily and removed once analysis is complete. The application does not require access to live CS2 game memory and is not designed to inject into or modify the game.

About the project

z3d's CS Enhancer is an independent player-development project currently being developed for Counter-Strike 2 players.
